# flower-shop-go
Это приложение Цветочного магазина "Василёк"

Реализована работа с магазином, пользователями и складом:

В магазине можно добавлять, корректировать и удалять пользователей - Продавцов
В магазине можно добавлять и удалять любые цветы

Данное ПО написано на:

1. Go 1.27 (backend)
2. Bootstrap (frontend)
3. Используется СУБД Postgres 18

Приложение — на открывается на IP-адресе хоста с докером - 0.0.0.0:8080 (настройки берутся из config.ini)
Войти директором: логин director, пароль admin123 и далее можно добавлять "Продавцов магазина"

Запустить приложение можно одной командой из рабочей директории
docker compose up --build

Данное ПО распространяется по лицензии Линукс и с принципом AS IS - т.е. без гарантий и ответственности...
